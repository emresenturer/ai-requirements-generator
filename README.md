# AI Requirements Generator

## Overview
This project demonstrates how AI can convert unstructured stakeholder meeting notes
into structured product requirements documentation.

The workflow transforms raw notes into:
• User stories
• Acceptance criteria
• Business rules
• Structured requirements documentation

---

## Problem

Business analysts often spend hours translating meeting discussions
into structured requirements documents.

This manual process is slow and inconsistent.

---

## Solution

This AI workflow:

1. Accepts raw meeting notes
2. Identifies business objectives
3. Generates structured requirements
4. Produces user stories and acceptance criteria
5. Outputs documentation ready for product teams

---

## Tools Used

Claude
ChatGPT
Notion
Python

---

## Example Output

Input: Stakeholder meeting notes

Output:
• User stories
• Acceptance criteria
• Functional requirements
• Non‑functional requirements

---

## Business Impact

Reduces documentation time by up to 70% and improves consistency across product teams.
